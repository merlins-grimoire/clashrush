# Clash Rush Rebuild

A Windows/BlueStacks runner being developed toward coordinated Home Village and
Builder Base progression, safe account rotation, reliable shutdown/recovery and
simple owner controls. The full product is not the current MVP or a release claim.

## Current milestone

The supported one-account Home attack/profile candidate has **final offline PASS**,
including source-bound empty/populated support and supplied-precommit-state profile
fit. It is a separate frozen candidate, not integrated main. Native account/build/
geometry, held-out/dynamic profile admission, installed-build and live gates remain
open. No complete-MVP acceptance or runtime/live/release approval is implied.

Start with [project law](.hermes.md) and [CURRENT.md](docs/architecture/CURRENT.md)
for exact identities, current gate, evidence limitations, future finite Home
acceptance and Vision/OCR's paused-before-creation status. This documentation-only
governance candidate neither integrates the software candidate nor starts a lane.

## Product boundaries

Native Windows input only; no ADB. One host-wide game-input/lifecycle owner. Preserve
the exact-five foundation until an explicitly reviewed state migration; one-account
Home proof does not establish arbitrary single-account installation. Later Setup,
Run, Pause, Resume, Stop, Status and Debug must not require routine source/JSON edits.
Full frames and private evidence follow the linked privacy policy. Optional remote
controls cannot widen gameplay, spending, image or lifecycle authority.

Historical Slice 1 was an inert lifecycle checkpoint, not the current repository's
entire implementation. Its old setup instructions and receipts remain Git history
and [version-specific reference](research/slice-1-contract.md), not permission to
install, initialize, launch or clear uncertain runtime state now. Private font/assets
remain ignored and are not redistributable without verified rights.
